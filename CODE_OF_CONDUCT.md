# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant].

In short: be respectful, assume good faith, and focus criticism on work rather than people.
Harassment, personal attacks, and discriminatory language are not tolerated in issues, pull
requests, or any other project space.

Report unacceptable behaviour to conduct@avala.ai. Reports are handled confidentially by the
maintainers, who will respond within five working days.

The full text of the Covenant applies, including its enforcement guidelines.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
