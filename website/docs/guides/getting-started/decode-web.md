# Decode in a browser

Written alongside the implementation this guide documents, so the commands in it are ones CI has
run. See the [feature matrix](../../reference/index.md) for what is implemented today.

Until then, the [specification](../../spec/index.md) and [concepts](../concepts.md) are the
reference.

## Scope

This guide ends where decoding ends: typed arrays of gaussian state at a time `t`, ready to hand to
whatever draws them. Rendering is out of scope for this project — see
[AGENTS.md](https://github.com/avala-ai/4dgs/blob/main/AGENTS.md).
